BYTE BACK 내 자료실

실습을 위해 만든 가상 메모를 사용하는 자료실입니다.

가상 메모는 DB에서 서버 API를 통해 읽습니다. 이전 공개 Git 커밋과 배포 이력은 삭제되지 않았습니다.

로그인 상태를 확인하는 중입니다.

기기 승인: 확인 정보 없음

현재 데모에서는 관리자가 이 페이지 접속을 승인하고 서버가 결과를 확인한 뒤 기존 자료실이 열립니다. 앱 설치나 로그인만으로 기기 승인이 완료되지는 않습니다.

연결 상태를 확인하는 중입니다.

오프라인에서는 연결 안내만 제공합니다. 메모 조회와 변경에는 인터넷 연결과 서버 확인이 필요합니다.

지원하는 브라우저의 메뉴에서 ‘앱 설치’ 또는 ‘홈 화면에 추가’를 선택할 수 있습니다.

탈환 작전실

관리자용 서버 요약입니다. 설치 표시·로컬 연습 결과를 실제 운영 결과로 세지 않습니다.

서버 요약을 아직 조회하지 않았습니다.
